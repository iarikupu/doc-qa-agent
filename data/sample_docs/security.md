# Security Practices

All laptops must use full-disk encryption and automatic screen lock after five minutes of inactivity. Lost or stolen devices must be reported to the security team within one hour.

Passwords must be at least 14 characters and are stored only in the approved password manager. Multi-factor authentication is mandatory for every system that holds customer data.

Production access is granted on request for a maximum of eight hours and every session is logged. Access reviews are performed every quarter by the security team.
